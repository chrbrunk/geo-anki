# Changelog

## v0.3.0

Adds support for India's districts.

- Devanagari and Bengali card fronts in selected states; English elsewhere.
- State and union-territory maps with reference cities and English answers.
- 731 historical district targets and a 10-card example deck.
- Varanasi example, source and font notices, and GeoGuessr-focused documentation.

## v0.2.0

Adds support for the Philippines, Bangladesh, Germany, and Japan.

- Japanese and Bengali card fronts with bilingual maps.
- Country-specific map views and reference cities.
- Full target lists and 10-card example decks for all five countries.
- Install from PyPI: `pip install geo-anki`.

## v0.1.0

Generate map-based Anki flashcards for Indonesia’s kabupaten and kota.

- Real geographic boundaries, downloaded automatically.
- Highlighted maps with province outlines and reference cities.
- Custom target lists and importable `.apkg` decks with embedded maps.
- Island-wide views for Java, Sumatra, Kalimantan, and Sulawesi.
- A 10-card example deck to try out.

Currently supports Indonesia only. More countries are planned.
